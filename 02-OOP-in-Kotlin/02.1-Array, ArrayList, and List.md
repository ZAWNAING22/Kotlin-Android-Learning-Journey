In **Kotlin (especially Android)**, `Array`, `ArrayList`, and `List` are very common. They all store multiple values, but they behave differently.

---

# 🔹 1. Array

Fixed size collection.
Once created, size cannot change.

```kotlin
val nums = arrayOf(1,2,3,4)
println(nums[0])   // 1
nums[1] = 10
println(nums[1])   // 10
```

### ✅ Empty Array

```kotlin
val empty = emptyArray<Int>()
```

### ✅ String Array

```kotlin
val names = arrayOf("Ali", "John", "Sara")
```

### ✅ Data Class Array

```kotlin
data class Student(val name:String, val age:Int)

val students = arrayOf(
    Student("Ali",20),
    Student("John",22)
)
```

---

# 🔹 2. ArrayList

Dynamic size collection.
Can add/remove items anytime.

```kotlin
val list = arrayListOf("Apple","Banana")
list.add("Orange")
list.remove("Banana")

println(list)
```

### ✅ Empty ArrayList

```kotlin
val numbers = arrayListOf<Int>()
val names = ArrayList<String>()
```

### ✅ Data Class in ArrayList

```kotlin
data class User(val id:Int, val name:String)

val users = arrayListOf<User>()

users.add(User(1,"Ali"))
users.add(User(2,"John"))
```
---
```kotlin
/*👉 In practice:

Use arrayListOf() when you want a quick, idiomatic Kotlin list with initial values.

Use ArrayList() when you need explicit control or interoperability with Java code */
```
---

# 🔹 3. List

Read-only collection (cannot add/remove directly).

```kotlin
val fruits = listOf("Apple","Banana","Orange")
println(fruits[0])
```

### ✅ Empty List

```kotlin
val empty = emptyList<String>()
```

### ✅ Mutable List (changeable)

```kotlin
val items = mutableListOf("A","B")
items.add("C")
```

---

# 🔥 Difference Table

| Type        | Size Change | Mutable      | Use                        |
| ----------- | ----------- | ------------ | -------------------------- |
| Array       | ❌ Fixed     | Elements yes | Simple fixed data          |
| ArrayList   | ✅ Dynamic   | Yes          | Most common old Java style |
| List        | ❌ Read-only | No           | Safe display data          |
| MutableList | ✅ Dynamic   | Yes          | Preferred Kotlin way       |

---

# 🔥 In Android Which Used Most?

✅ `MutableList` → RecyclerView/ListView data
✅ `ArrayList` → Intent passing, Adapter old style
✅ `Array<String>` → Spinner items, fixed values

# 🔥 When To Use What

### Use Array when:

* Fixed values
* Known size
* Fast access

### Use ArrayList / MutableList when:

* Add/remove items
* Dynamic data from API/database

### Use List when:

* Display only
* Prevent accidental changes
